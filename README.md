A Python program that writes a ~100-word villain monologue to `/output/entry.txt`. The speaker is Magda Salt-Hands, a witch of the White Flats who has spent three hundred years salting the kingdom's fields pinch by pinch — and who tonight salts the mountain pass so the hero's army starves before the gate. Her exhaustion lives in the rhythm, the pauses, and the small deflections, never in a word that names it.

## Run

```sh
python3 main.py
```

For local testing, point the output elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` (100 words, 505 characters, UTF-8) to the output directory. The program is deterministic: two runs produce byte-identical output.
